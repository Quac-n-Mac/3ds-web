# 3ds-web

Nintendo 3DS emulator that runs in the browser (Azahar, WebAssembly build by Shubin123/azahar_web).

Play: https://quac-n-mac.github.io/3ds-web/

Load your own decrypted .3ds / .3dsx / .cci ROM from the page. Nothing is hosted here but the emulator itself.

Controls: arrows = circle pad, T/G/F/H = d-pad, A/S/Z/X = A/B/X/Y, Q/W = L/R, M = start, N = select. Touch works on the bottom screen. Saves and save states stay in the browser.
